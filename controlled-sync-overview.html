为什么你提的诉求

✗ 不要：改一处 → 无脑自动全改（链路长、易失控，最后「一团杂糅」不知道改了哪）。
✓ 要的是：改 SSOT.md 一处 → 其他镜像随之变，但有记录、能找回。

流程图受控同步怎么跑

回滚路径：整体回退 git revert <hash> · 只还原某个文件 git checkout <hash>^ -- <文件>
注意：git checkout -- <文件> 是从暂存区恢复（可能停在旧值），要回到最新已提交版本请用 git checkout HEAD -- <文件>。
